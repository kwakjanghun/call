# ppt — 수업용 발표 자료 + 대본 자동 제작

사용법: `/ppt <원자료 파일 경로>` (파일 첨부와 함께 호출해도 됨)

## 산출물 (두 가지, 모두 `수업자료/` 폴더에)

1. **발표 자료** `수업자료/<주제>_발표자료_YYYYMMDD_vNN.html`
   - 단일 자기완결형 HTML (CSS·JS 전부 인라인, 오프라인 동작)
   - `html-ppt` 스킬의 base.css + tokyo-night 테마 + animations.css + runtime.js를 인라인
   - 키보드: ← → 이동 · `F` 전체화면 · `S` 발표자 화면(대본·타이머) · `N` 대본 서랍 · `O` 개요
2. **발표 대본** `수업자료/<주제>_발표대본_YYYYMMDD_vNN.md`
   - 슬라이드별 구어체 대본 + 차시 시간 배분 + 교사용 시험 포인트 표

## 작업 순서

1. **원자료 읽기**: PDF는 `pdf` 스킬(pypdf/pdfplumber)로 텍스트 추출. 내용을 지어내지 말고 원자료의 개념·용어·수치(핀 번호, 주소값 등)를 그대로 반영한다.
2. **구성 설계**: 표지 → 학습 목표 → (개요 → 원리 → 코드 → **코드 한 줄씩 해설** → 회로 → 실행)×실습 수 → 연습 문제 → 정답·해설 → 정리. 원자료 순서를 따르되 수업 흐름에 맞게 재구성 가능.
   - **라인별 코드 해설 페이지는 필수 — 한 줄 = 한 페이지.** 코드 요약 슬라이드 바로 뒤에, 의미 있는 코드 한 줄마다 페이지 하나를 만든다(빈 줄·중괄호만 있는 줄은 제외). 이 자료는 PPT를 대신해 수업·영상 제작에 쓰이므로 글씨를 크게:
     - 페이지 중앙에 그 줄의 코드를 **큰 글씨(36px 내외)**로 띄우고, 인자마다 색깔 칩(`.lf-arg .lf-a1~a4`)으로 감싼다.
     - 그 아래 한 문장으로 "이 줄이 하는 일"(`.lf-role`, 24px 내외), 이어서 **인자별 큰 카드**(`.lf-card c1~c4`, 카드 제목 = 인자값, 본문 18px 이상)로 각 인자의 의미를 자세히 설명한다. 칩과 카드의 색을 맞춘다.
     - 오른쪽에 전체 코드 미니맵(`.lf-map`)을 두고 현재 줄을 하이라이트(`.cur`)해 위치를 보여 준다.
     - kicker에 "실습 N · 코드 해설 i / 총수"로 진행도를 표기하고, 슬라이드 notes에 그 줄의 발표 대본을 넣는다(영상 내레이션으로도 활용).
     - 레이아웃·CSS 예시는 기존 발표자료(`수업자료/6장_디스플레이_발표자료_20260807_v03.html`)의 `.lf-*` 스타일과 "코드 해설" 슬라이드 참고.
3. **표지 애니메이션**: 주제와 어울리는 애니메이션을 JS/CSS로 직접 구현해 표지에 넣는다 (예: 디스플레이 단원 → 7세그먼트 카운트업 + 도트매트릭스 점등). 기존 예시는 `수업자료/6장_디스플레이_발표자료_20260807_v03.html`의 마지막 `<script>` 블록 참고.
4. **대본 작성**: 각 슬라이드 안에 `<div class="notes">`로 구어체 대본(발표자 화면용)을 넣고, 같은 내용을 별도 `_발표대본_.md`로도 저장. 대본은 존댓말 구어체, 비유·질문 던지기 포함, 슬라이드당 3~6문장 + 시간 배분.
5. **필수 요소**: 시험 포인트 표시(⭐/📝), 실습 시간 안내, 자료 출처 표기(deck-footer), 슬라이드 번호.
6. **검증**: 헤드리스 크롬으로 표지·핵심 슬라이드 스크린샷을 찍어 레이아웃 확인 후 전달.
   ```bash
   /opt/pw-browsers/chromium --headless --no-sandbox --window-size=1600,900 \
     --screenshot=out.png "file://<html경로>#/1" --virtual-time-budget=4000
   ```
7. **마무리**: 결과물 커밋·푸시 후 SendUserFile로 사용자에게 전송.

## 조립 방법 (자기완결형 HTML)

템플릿 HTML에 플레이스홀더(`/*__BASE_CSS__*/`, `/*__ANIM_CSS__*/`, `/*__RUNTIME_JS__*/`)를 두고 python으로 `.claude/skills/html-ppt/assets/`의 base.css, animations/animations.css, runtime.js 내용을 치환해 한 파일로 만든다. 웹폰트 CDN은 쓰지 않는다(오프라인 보장).

## 문체 규칙

- 청중: 고등학생. 존댓말 구어체, 짧은 문장, 생활 속 비유(전자레인지, 전광판, 줄넘기 박자 등).
- 슬라이드는 청중용 텍스트만, 발표자용 말은 전부 `.notes`에.
- 원자료가 저작물이면 출처를 footer에 명시하고 "수업용" 표기.
