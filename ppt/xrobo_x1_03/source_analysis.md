# XROBO_Extreme_X1_03 (엑스쿠터 컨트롤) — mBlock 프로젝트 소스 분석

- 파일: XROBO_Extreme_X1_03______v250521.mblock (mBlock 5 프로젝트, ZIP 컨테이너)
- 장치: xrobo_learnkit 확장 v0.2.2 (업로드 모드: Arduino C)
- 스크립트: 메인 스크립트 1개 + 사용자 정의 함수("엑스쿠터 컨트롤") 1개

## 메인 스크립트
1. 시작 블록 (RF 자동 연결 옵션 = 1)
2. 설정 블록: 핀 0, 값 20 (초기 설정)
3. 무한 반복:
   - 10번 반복: [함수 "엑스쿠터 컨트롤" 호출 → 0.2초 기다리기]  (합계 약 2초의 리모컨 감지 구간)
   - 모터 좌 10 / 우 10, 1000ms (전진 1초) → 0.5초 대기
   - 모터 좌 -10 / 우 -10, 1000ms (후진 1초) → 0.5초 대기
   - 부저 7음 멜로디: 523, 587, 659, 587, 523, 587, 659 Hz (각 재생 50ms + 쉼 100ms)
     = 도5 레5 미5 레5 도5 레5 미5

## 사용자 함수 "엑스쿠터 컨트롤"
- 만약 리모컨 수신값(A6) == 1 이면:
  - 시작 알림음 3개: 262, 294, 321 Hz (각 100ms 재생 + 150ms 쉼) ≈ 도4 레4 미4
  - 무한 반복 (리모컨 제어 모드 — 복귀하지 않음):
    - A6 == 1 → 모터 좌 20 / 우 20 (전진)
    - A6 == 2 → 모터 좌 -20 / 우 -20 (후진)
    - A6 == 5 → 멜로디 7음 (523,587,659,587,523,587,659)
    - 그 외   → 모터 0 / 0 (정지)

## 핵심 교육 포인트
- 순차 / 반복 / 선택 구조 + 함수(추상화) 모두 포함
- 폴링(polling) 방식 입력 감지: 0.2초 × 10회
- 모터 속도의 부호 = 회전 방향, 좌우 같은 값 = 직진
- 주파수(Hz)와 음계의 관계 (262≈C4, 523≈C5 등, 321은 E4=330의 근사값)
- 함수 내부 무한 루프 진입 시 메인 루프로 복귀하지 않는 구조적 특징
