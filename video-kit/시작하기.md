# 보강영상 제작 키트 — 사용법

PDF 수업자료 → 나레이션 음성 영상(mp4)을 전부 무료로 만드는 키트입니다.
(리모션 + edge-tts. 개인·교육 용도 무료, 사용량 제한 없음)

## 처음 한 번만 (설치)

이 폴더를 클로드 코드 작업 폴더로 지정하고, 아래를 붙여넣으세요:

```
이 폴더는 리모션 영상 제작 키트야. 설치를 해 줘:
1. npm install
2. pip install edge-tts mutagen
설치가 끝나면 "python tools/make_narration.py" 로 예시 음성을 만들고
"npm run render" 로 예시 영상(7장 LCD와 서보모터)을 렌더링해서 확인시켜 줘.
```

완성 영상은 `out/video.mp4` 에 생깁니다.

## 새 영상 만들기 (매번)

새 PDF와 함께 클로드 코드에 이렇게 지시하세요:

```
[PDF 파일 첨부 또는 경로 지정]
이 PDF를 참고해서 content/scenes.json 을 새로 작성해 줘.
- 장면 6~10개, 각 장면에 badge/title/lines(핵심 3줄 이내)/narration(말로 읽는 대본)
- 내용·용어·수치는 반드시 PDF에서 가져올 것
- 시험 포인트 장면 1개 포함
작성이 끝나면 python tools/make_narration.py 로 음성을 만들고
npm run render 로 영상을 렌더링해 줘.
```

## 목소리 바꾸기

`content/scenes.json`의 `"voice"` 값을 바꾸면 됩니다:
- `ko-KR-InJoonNeural` — 남성 (기본)
- `ko-KR-SunHiNeural` — 여성
- 전체 목록: `edge-tts --list-voices | grep ko-KR`

## 새로운 다이어그램(그림)이 필요하면

`src/diagrams.tsx` 에 장면용 SVG 애니메이션이 들어 있습니다.
클로드 코드에게 "○○ 원리를 보여주는 다이어그램을 추가해 줘"라고 하면
새 컴포넌트를 만들어 scenes.json 의 `"diagram"` 키로 연결해 줍니다.

## 폴더 구조

```
video-kit/
├─ content/scenes.json      ← 영상 내용(장면·대본). 매번 이것만 바뀜
├─ tools/make_narration.py  ← 음성 생성 (edge-tts)
├─ src/                     ← 리모션 코드 (디자인·애니메이션)
├─ public/audio/            ← 생성된 음성 (자동)
├─ public/fonts/            ← 한글 폰트 (Noto Sans KR)
└─ out/video.mp4            ← 완성 영상
```
